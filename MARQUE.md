## 1. Pourquoi une politique à part

CoproFirst est un logiciel libre sous **AGPL-3.0-or-later** ([`NOTICE.md`](NOTICE.md)) :
chacun peut l'utiliser, le modifier, l'héberger et le proposer comme service, y
compris contre paiement. La licence porte sur le **code** ; elle ne règle pas
l'usage des **noms**. Ce document le fait, pour une seule raison : qu'un utilisateur
sache **qui** lui fournit le service qu'il emploie.

## 2. Ce qui est protégé, et comment

| Signe | Protection | État au 10/10/2026 |
|---|---|---|
| **CoproFirst** (le mot, quelle que soit sa graphie) | marque française **verbale**, classes 9 (logiciels), 36 (services immobiliers) et 42 (logiciel en tant que service) | **demande d'enregistrement** INPI n° **5307183**, déposée le 09/10/2026 ; publication prévue le 30/10/2026 ; délai d'opposition jusqu'au 30/12/2026 |
| **5Hostachy** | aucune marque : c'est le nom de la résidence pour laquelle le projet est né, et celui de son site | non déposé |
| le **logo** et l'identité visuelle | aucune marque ; leurs fichiers sont distribués sous la licence du dépôt, comme le reste | non déposé |

Sources des délais : la propriété d'une marque s'acquiert par l'enregistrement, qui
prend effet à la date du dépôt pour dix ans renouvelables (CPI art. L.712-1) ; un
tiers peut former opposition dans les **deux mois** qui suivent la publication de
la demande (CPI [art. L.712-4](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000039381569),
rédaction de l'ordonnance n° 2019-1169 du 13/11/2019). Tant que la demande n'est
pas enregistrée, la mention est « CoproFirst — demande de marque n° 5307183 »,
**jamais** le symbole ®.

## 3. Ce qui est permis sans rien demander

- **Désigner le logiciel d'origine** : écrire qu'un service « repose sur
  CoproFirst », « est une version modifiée de CoproFirst » ou « est compatible avec
  CoproFirst ». Le code de la propriété intellectuelle le permet, dans les usages
  loyaux du commerce et sans confusion sur l'origine (CPI art. L.713-6).
- **Faire fonctionner une version non modifiée** sous son nom : une installation
  qui sert le code publié, tel quel, est CoproFirst.
- **En parler** : article, comparatif, formation, critique.
- **Garder les mentions** que la licence impose : copyright, lien vers le code
  source (AGPL §13), le lien « CoproFirst » du pied de page qui y mène.

## 4. Ce qui ne l'est pas

- **Présenter une version modifiée sous le nom CoproFirst**, comme si elle était le
  logiciel d'origine. Une version modifiée prend **un autre nom**, et peut dire
  qu'elle dérive de CoproFirst (§3).
- **Nommer un produit, un service, une société ou un domaine** d'un nom qui
  reprend CoproFirst ou s'en approche au point de prêter à confusion.
- **Laisser croire** à un partenariat, une certification ou un soutien de l'auteur
  qui n'existe pas.

## 5. Le logo et le nom 5Hostachy

Aucun des deux n'est une marque déposée. Les fichiers du logo sont sous la licence
du dépôt : on peut les copier et les modifier avec le code. L'auteur **demande**
néanmoins qu'ils ne servent pas à signer une version modifiée, ni un service sans
rapport avec la résidence 5Hostachy — c'est une demande, pas un droit que cette
page créerait. Ce qui reste interdit dans tous les cas, c'est de tromper le public
sur l'origine d'un service.
